# 电容计算算法

## 1. 单次两端电容测量

DDS 输出固定 1 MHz 正弦信号。AD9238 同时采集：

- `VH`：电桥输入端电压，程序自动把基波峰峰值较大的一路判定为 VH；
- `VL`：参考电阻 `R0` 两端电压，基波峰峰值较小的一路。

程序对两路各取 2000 个采样点，在 1 MHz 频点执行单点 DFT：

```text
Re = sum(x[n] * cos(2*pi*f*n/Fs))
Im = -sum(x[n] * sin(2*pi*f*n/Fs))
V  = Re + j*Im
```

采样率 `Fs=10 MHz`，2000 点正好包含 200 个 1 MHz 周期，不加窗函数。

参考电阻电流为：

```text
I = VL / R0
```

待测元件两端电压为：

```text
VX = VH - VL
```

所以复阻抗为：

```text
Z = VX / I = R0 * (VH - VL) / VL = R + jX
```

如果 `X < 0`，待测元件呈电容性。采用串联等效模型：

```text
Z = ESR - j/(2*pi*f*Cs)
Cs = -1/(2*pi*f*X)
```

换算成 pF：

```text
Cs_pF = -1e12 / (2*pi*f*X)
```

程序把最终结果写入 `g_ad9238_capacitance_result`：

- `series_capacitance_pf`：串联等效电容，单位 pF；
- `series_capacitance_nf`：串联等效电容，单位 nF；
- `equivalent_series_resistance_ohm`：ESR；
- `dissipation_factor = abs(ESR/X)`；
- `valid_mask & 1` 为 1 时电容结果有效。
