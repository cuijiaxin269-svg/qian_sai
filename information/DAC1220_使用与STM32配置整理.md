## 第 1 部分：DAC1220 基本使用方法与使用逻辑整理

> 适用场景：你想用 STM32 / 单片机通过串行接口控制 DAC1220，输出一个高精度、低速变化的模拟电压，例如偏置电压、控制电压、校准电压、慢速闭环控制量等。

---

### 1. DAC1220 最基本的功能是什么？

DAC1220 是一颗 **20 位低功耗电压输出 DAC**。

它的基本作用可以理解为：

> 单片机发送一个数字码值 → DAC1220 把这个数字码值转换成一个模拟电压输出。

它不是高速波形 DAC，不适合拿来直接产生 1 MHz 正弦波这类高速信号。它更适合输出稳定的直流电压或者慢速变化的控制电压。

---

### 2. 关键特性总结

| 项目 | 说明 |
|---|---|
| 分辨率 | 可选 16 位或 20 位 |
| 输出类型 | 电压输出 |
| 输出范围 | 约为 `0 ~ 2 × VREF` |
| 常用参考电压 | `VREF = 2.5 V` |
| 常用输出范围 | `0 ~ 5 V` |
| 供电 | AVDD、DVDD 通常都是 +5 V |
| 接口 | 类 SPI 的同步串行接口，使用 SCLK、SDIO、CS |
| 输出电流能力 | 很弱，典型只适合轻载，最大约 0.5 mA |
| 建议用途 | 高精度慢速控制电压、偏置电压、校准电压 |
| 不适合用途 | 高速波形输出、大电流驱动、直接带负载 |

---

### 3. 它的内部逻辑怎么理解？

DAC1220 内部不是普通 R-2R DAC，而是 **ΔΣ DAC**。

可以简单理解为：

1. 单片机把目标数字码写入 DAC1220 的数据寄存器；
2. 芯片内部用 ΔΣ 调制和滤波结构生成高精度模拟电压；
3. 模拟输出端 VOUT 输出对应电压；
4. 因为内部有滤波，所以它的输出响应不是瞬间完成的，而是需要一定建立时间。

所以它的优点是精度高、单调性好、功耗低；缺点是速度慢。

---

### 4. 基本引脚连接

#### 4.1 电源与地

| DAC1220 引脚 | 连接方式 |
|---|---|
| AVDD | +5 V 模拟电源 |
| DVDD | +5 V 数字电源 |
| AGND | 模拟地 |
| DGND | 数字地 |
| VREF | 外部 2.5 V 精密参考源 |
| VOUT | 模拟电压输出 |

一般情况下，AVDD 和 DVDD 都接 5 V。AGND 和 DGND 建议在芯片附近合理共地，模拟部分尽量保持干净。

注意：

- DVDD 不允许明显高于 AVDD；
- AVDD、DVDD 都要在芯片附近放去耦电容；
- 推荐每个电源脚附近放 `0.1 µF`，再配合 `4.7 µF ~ 10 µF` 电容；
- VREF 一定要用低噪声、稳定的参考源，不要随便用普通 2.5 V 分压。

---

#### 4.2 时钟连接

DAC1220 需要主时钟 XIN。

常用方法有两种：

##### 方法 1：使用 2.5 MHz 晶体

| 引脚 | 连接 |
|---|---|
| XIN | 晶体一端 |
| XOUT | 晶体另一端 |
| 晶体两端 | 各接一个负载电容到地 |

常见图中会给出约 12 pF 负载电容，但实际值要根据晶体负载电容和 PCB 寄生电容调整。

##### 方法 2：外部时钟输入

| 引脚 | 连接 |
|---|---|
| XIN | 接外部 CMOS/TTL 时钟 |
| XOUT | 悬空 |

外部时钟典型使用 2.5 MHz。时钟频率会影响串口时序、噪声和建立时间，所以不要随意偏离太多。

---

#### 4.3 输出滤波电容 C1、C2

DAC1220 外部必须接 C1、C2，用于内部连续时间输出滤波。

| 工作模式 | C1 | C2 |
|---|---:|---:|
| 16 位模式 | 2.2 nF | 0.22 nF |
| 20 位模式 | 10 nF | 3.3 nF |

建议：

- C1、C2 用高品质、稳定电容；
- 尽量靠近 DAC1220；
- 走线要短；
- C1、C2 节点非常敏感，布局时要远离数字信号、时钟线和开关电源噪声。

---

### 5. 输出电压怎么算？

DAC1220 的理想输出范围是：

```text
VOUT = 0 ~ 2 × VREF
```

如果 `VREF = 2.5 V`，则：

```text
VOUT = 0 ~ 5 V
```

#### 5.1 推荐先使用 Straight Binary 格式

对于初学和单片机控制，建议先把数据格式设置成 **Straight Binary**。

这样最直观：

| 目标电压 | 16 位码值 | 20 位码值 |
|---:|---:|---:|
| 0 V | 0x0000 | 0x00000 |
| 2.5 V | 0x8000 | 0x80000 |
| 5 V | 0xFFFF | 0xFFFFF |

计算公式：

#### 16 位模式

```text
code16 = VOUT / (2 × VREF) × 65535
```

如果 `VREF = 2.5 V`：

```text
code16 = VOUT / 5.0 × 65535
```

#### 20 位模式

```text
code20 = VOUT / (2 × VREF) × 1048575
```

如果 `VREF = 2.5 V`：

```text
code20 = VOUT / 5.0 × 1048575
```

### 6. DAC1220 的寄存器逻辑

DAC1220 主要通过寄存器控制。

| 地址 | 内容 | 说明 |
|---:|---|---|
| 0 | DIR byte 2 | 数据寄存器 MSB |
| 1 | DIR byte 1 | 数据寄存器中间字节 |
| 2 | DIR byte 0 | 数据寄存器 LSB |
| 4 | CMR byte 1 | 命令寄存器 MSB |
| 5 | CMR byte 0 | 命令寄存器 LSB |
| 8 | OCR byte 2 | 偏移校准寄存器 MSB |
| 9 | OCR byte 1 | 偏移校准寄存器 |
| 10 | OCR byte 0 | 偏移校准寄存器 LSB |
| 12 | FCR byte 2 | 满量程校准寄存器 MSB |
| 13 | FCR byte 1 | 满量程校准寄存器 |
| 14 | FCR byte 0 | 满量程校准寄存器 LSB |

最常用的就是两个寄存器：

1. **CMR：Command Register**  
   用来设置模式、分辨率、数据格式、校准模式等。

2. **DIR：Data Input Register**  
   用来写入你想输出的 DAC 码值。

---

### 7. 串行接口使用逻辑

DAC1220 的通信方式类似 SPI，但它是 **单数据线 SDIO**。

基本信号：

| 信号 | 方向 | 说明 |
|---|---|---|
| SCLK | MCU → DAC1220 | 串行时钟 |
| SDIO | 双向或单向 | 数据输入/输出 |
| CS | MCU → DAC1220 | 片选，低有效 |

如果你只写 DAC，不读寄存器，那么 SDIO 可以当作单向 MOSI 使用。

---

### 8. SPI 时序要点

DAC1220 的时序重点是：

- SCLK 控制串行传输；
- DAC1220 在 **SCLK 下降沿锁存输入数据**；
- DAC1220 在 **SCLK 上升沿移出输出数据**；
- 命令字节永远是 MSB first；
- 数据字节的 bit 顺序可以配置，但建议保持默认 MSB first；
- 传输以字节为单位；
- CS 低有效；
- 如果不用 CS，可以直接把 CS 接地，但多器件 SPI 总线不建议这样做；
- SCLK 频率不能太高，通常限制为主时钟频率的 1/10。例如 XIN = 2.5 MHz 时，SCLK 不要超过约 250 kHz。

对于 STM32，配置 SPI 时不要盲目追求高速，先把 SCLK 降到 100 kHz ~ 200 kHz，确认能稳定通信后再优化。

---

### 9. 命令字节格式

DAC1220 每次通信都从一个命令字节开始。

命令字节格式：

```text
bit7     bit6~5      bit4      bit3~0
R/W      MB          0         ADR
```

| 字段 | 说明 |
|---|---|
| R/W | 0 = 写寄存器，1 = 读寄存器 |
| MB | 读/写几个字节 |
| ADR | 起始寄存器地址 |

MB 字段含义：

| MB | 字节数 |
|---|---:|
| 00 | 1 字节 |
| 01 | 2 字节 |
| 10 | 3 字节 |
| 11 | 保留，不要用 |

常用命令字节：

| 操作 | 命令字节 | 说明 |
|---|---:|---|
| 写 2 字节到 DIR | 0x20 | 16 位模式写输出码 |
| 写 3 字节到 DIR | 0x40 | 20 位模式写输出码 |
| 写 2 字节到 CMR | 0x24 | 配置命令寄存器 |
| 读 2 字节 CMR | 0xA4 | 回读命令寄存器 |

### 10. 基本初始化流程

推荐启动流程：

```text
上电
  ↓
等待晶振稳定，至少约 25 ms
  ↓
可选：发送 SCLK reset pattern
  ↓
写 CMR，设置分辨率、数据格式、工作模式
  ↓
执行自校准
  ↓
等待校准完成，或延时 500 ms
  ↓
写 DIR，输出目标电压
```

实际使用中，最小可用流程可以简化为：

```text
上电 → 等待时钟稳定 → 写 CMR → 等待/校准 → 写 DIR
```

### 11. 推荐配置思路

#### 11.1 初学推荐：16 位 + Straight Binary

原因：

- 16 位速度更快；
- 数据计算简单；
- 输出建立时间短；
- 对 STM32 控制更容易；
- 绝大多数偏置/控制电压已经够用。

推荐 C1、C2：

```text
C1 = 2.2 nF
C2 = 0.22 nF
```

推荐数据格式：

```text
Straight Binary
```

也就是：

```text
0x0000 → 0 V
0x8000 → 2.5 V
0xFFFF → 约 5 V
```

---

#### 11.2 高精度推荐：20 位 + Straight Binary

适合更高精度、慢速控制。

推荐 C1、C2：

```text
C1 = 10 nF
C2 = 3.3 nF
```

注意：

- 20 位建立时间更长；
- 写 DIR 时需要写 3 字节；
- 对参考源、布局、电源噪声要求更高；
- 如果后级电路噪声较大，20 位的优势可能体现不出来。

---

### 12. 写输出电压的逻辑

#### 12.1 16 位模式写法

16 位模式下，只需要写 DIR 的高 2 字节。

假设要输出 `VOUT`，`VREF = 2.5 V`：

```c
uint16_t code = (uint16_t)(VOUT / 5.0f * 65535.0f);
```

发送：

```text
CS 拉低
发送命令字节 0x20
发送 code 高 8 位
发送 code 低 8 位
CS 拉高
```

例如：

| 目标输出 | code | 发送数据 |
|---:|---:|---|
| 0 V | 0x0000 | 0x20 0x00 0x00 |
| 2.5 V | 0x8000 | 0x20 0x80 0x00 |
| 5 V | 0xFFFF | 0x20 0xFF 0xFF |

---

#### 12.2 20 位模式写法

20 位模式下，需要写 DIR 的 3 字节。20 位数据左对齐到 24 位寄存器，高 20 位有效，低 4 位无效。

假设：

```c
uint32_t code20 = (uint32_t)(VOUT / 5.0f * 1048575.0f);
uint32_t dir = code20 << 4;
```

发送：

```text
CS 拉低
发送命令字节 0x40
发送 dir[23:16]
发送 dir[15:8]
发送 dir[7:0]
CS 拉高
```

例如：

| 目标输出 | 20 位 code | DIR 内容 |
|---:|---:|---:|
| 0 V | 0x00000 | 0x000000 |
| 2.5 V | 0x80000 | 0x800000 |
| 5 V | 0xFFFFF | 0xFFFFF0 |

---

```c
static void DAC1220_CS_High(void)
{
    // HAL_GPIO_WritePin(DAC_CS_GPIO_Port, DAC_CS_Pin, GPIO_PIN_SET);
}

static void DAC1220_WriteBytes(uint8_t cmd, const uint8_t *data, uint8_t len)
{
    DAC1220_CS_Low();

    // SPI_SendByte(cmd);
    // for (uint8_t i = 0; i < len; i++)
    // {
    //     SPI_SendByte(data[i]);
    // }

void DAC1220_WriteCMR(uint16_t cmr)
{
    uint8_t data[2];

    data[0] = (uint8_t)(cmr >> 8);
    data[1] = (uint8_t)(cmr & 0xFF);

    DAC1220_WriteBytes(DAC1220_CMD_WRITE_2B(DAC1220_ADDR_CMR), data, 2);
}

void DAC1220_SetVoltage_16bit(float vout, float vref)
{
    float full_scale = 2.0f * vref;

    if (vout < 0.0f) vout = 0.0f;
    if (vout > full_scale) vout = full_scale;

    uint16_t code = (uint16_t)((vout / full_scale) * 65535.0f);

    uint8_t data[2];
    data[0] = (uint8_t)(code >> 8);
    data[1] = (uint8_t)(code & 0xFF);

    DAC1220_WriteBytes(DAC1220_CMD_WRITE_2B(DAC1220_ADDR_DIR), data, 2);
}

void DAC1220_SetVoltage_20bit(float vout, float vref)
{
    float full_scale = 2.0f * vref;

    if (vout < 0.0f) vout = 0.0f;
    if (vout > full_scale) vout = full_scale;

    uint32_t code20 = (uint32_t)((vout / full_scale) * 1048575.0f);
    uint32_t dir = code20 << 4;   // 20位数据左对齐到24位DIR

    uint8_t data[3];
    data[0] = (uint8_t)(dir >> 16);
    data[1] = (uint8_t)(dir >> 8);
    data[2] = (uint8_t)(dir & 0xFF);

    DAC1220_WriteBytes(DAC1220_CMD_WRITE_3B(DAC1220_ADDR_DIR), data, 3);
}
```

### 14. 校准怎么理解？

DAC1220 内部带自校准功能，主要用于减小：

- 偏移误差；
- 增益误差。

简单理解：

> 芯片自己测量输出误差，然后把修正值写入内部校准寄存器，使后续输出更准。

自校准一般在上电初始化后执行一次。

自校准期间，输出可能会变化，也可能被断开，取决于 CMR 中 CALPIN 位的设置。

实用建议：

- 普通应用：上电后执行一次自校准；
- 如果不做寄存器回读：校准后直接延时约 500 ms；
- 温度变化很大、精度要求很高时，可以重新校准；
- 校准时后级电路最好不要依赖 DAC 输出处于稳定状态。

### 15. 输出端是否需要缓冲？

DAC1220 的 VOUT 输出电流能力很弱，不适合直接带负载。

如果后级输入阻抗很高，例如运放输入、ADC 参考输入、比较器输入，一般可以直接接。

如果后级负载较重，或者连线较长，建议加一级运放缓冲。

你上传的 TP2582 是一颗双运放，可以作为低速控制电压的缓冲选择之一。它的带宽和压摆率对 DAC1220 这种慢速电压输出通常是够用的，但要注意：

- TP2582 不是精密零漂运放；
- 它有输入失调电压，可能给高精度 DAC 输出带来毫伏级误差；
- 如果你追求 DAC1220 的 20 位精度，后级运放、参考源、电源噪声、PCB 泄漏都会限制最终精度；
- 如果只是作为 0~5 V 控制电压或偏置输出，TP2582 可以考虑。

常见连接：

```text
DAC1220 VOUT → 运放同相输入
运放输出 → 运放反相输入
运放输出 → 后级电路
```

这就是电压跟随器。

### 16. 布局布线注意事项

DAC1220 是高分辨率 DAC，PCB 布局会明显影响效果。

建议：

1. **VREF 走线要短、干净**
   - 远离 SCLK、SDIO、MCU 时钟线；
   - 参考源旁边要有去耦电容；
   - 不要让大电流回流经过参考源地。

2. **C1、C2 靠近芯片**
   - 走线越短越好；
   - 周围不要跑数字线；
   - 尽量避免开关电源噪声耦合。

3. **模拟地和数字地处理**
   - AGND、DGND 要共地；
   - 数字信号回流不要穿过 VREF 和 VOUT 的敏感区域。

4. **SPI 线不要太快**
   - SCLK 频率先用 100 kHz ~ 200 kHz；
   - 必要时串 22 Ω ~ 100 Ω 电阻减缓边沿；
   - SDIO 如果双向使用，注意释放总线和上拉。

5. **输出端不要直接拖重负载**
   - 需要驱动能力时加缓冲运放；
   - 长线输出时注意稳定性和输出保护。

### 17. 常见问题

#### 17.1 为什么写了码值，输出没变化？

检查顺序：

1. AVDD、DVDD 是否都是 5 V；
2. AGND、DGND 是否共地；
3. VREF 是否有 2.5 V；
4. XIN 时钟是否正常；
5. CS 是否正确拉低；
6. SCLK 是否过快；
7. SPI 采样边沿是否错误；
8. 是否仍处于 Sleep 或校准状态；
9. C1、C2 是否漏焊或数值错误；
10. VOUT 后级是否把输出拉死。

---

#### 17.2 为什么输出范围不是 0~5 V？

DAC1220 的输出范围约为：

```text
0 ~ 2 × VREF
```

如果 VREF 不是 2.5 V，输出满量程也不是 5 V。

例如：

| VREF | 输出范围 |
|---:|---:|
| 2.048 V | 0 ~ 4.096 V |
| 2.5 V | 0 ~ 5.0 V |

---

#### 17.3 为什么靠近 0 V 或 5 V 时误差变大？

DAC1220 的输出不是完全轨到轨高精度线性的。虽然理论输出是 0 到 2×VREF，但是最大线性范围更适合避开电源轨附近。

实际做高精度控制时，尽量不要让目标电压长期贴近 0 V 或 AVDD。

---

#### 17.4 16 位和 20 位应该选哪个？

| 需求 | 建议 |
|---|---|
| 先调通电路 | 16 位 |
| 输出偏置/控制电压 | 16 位通常够用 |
| 高精度慢速校准 | 20 位 |
| 对响应速度有要求 | 16 位 |
| 参考源和 PCB 一般 | 16 位更实际 |
| 后级噪声很低、温漂控制好 | 可以尝试 20 位 |

---

### 18. 最小调通步骤

建议你第一次调试时按下面做：

1. AVDD = 5 V，DVDD = 5 V；
2. VREF = 2.5 V；
3. XIN 输入 2.5 MHz，或使用 2.5 MHz 晶体；
4. C1 = 2.2 nF，C2 = 0.22 nF；
5. SPI SCLK 设置为 100 kHz；
6. 使用 16 位模式；
7. 使用 Straight Binary；
8. 先写 0x0000，看 VOUT 是否接近 0 V；
9. 再写 0x8000，看 VOUT 是否接近 2.5 V；
10. 再写 0xFFFF，看 VOUT 是否接近 5 V；
11. 确认这三点正常后，再考虑校准、20 位模式和缓冲电路。

### 19. 一句话总结

DAC1220 的使用逻辑就是：

> 供电、参考源、时钟和 C1/C2 先接好；单片机用低速 SPI 写 CMR 配置模式，再写 DIR 更新输出码；VOUT 就会按照 `0 ~ 2×VREF` 的范围输出对应电压。初学建议先用 16 位 Straight Binary，把 0 V、2.5 V、5 V 三个点调通。

## 第 2 部分：DAC1220 模块与 STM32H743VGTx 的 CubeMX SPI 配置

本文整理 DAC1220 成品模块配合 STM32H743VGTx 使用时，在 STM32CubeMX 中如何选择 SPI、配置引脚，以及后续程序实现逻辑。

### 1. 模块输出能力说明

这里使用的是 DAC1220 成品模块，不是裸 DAC1220 芯片。

模块手册说明：

- 输出范围：`-5V ~ +5V` 或 `-10V ~ +10V`
- 通过模块上的跳帽 `H2` 切换输出范围
- 通信接口：SPI
- 通信电平：`3.3V`
- 通信速率：最高约 `250kHz`
- 模块供电：约 `5V`，手册建议略大于 `5V`，但不要超过 `5.3V`

模块内部已经包含升压、负压和运放调理电路，因此如果选择 `-10V ~ +10V` 档，不需要再额外加 2 倍运放。

如果目标是输出 `0V ~ 10V` 直流电压，直接把模块跳帽设置到 `±10V` 档，然后在程序中只输出 `0V ~ 10V` 这个区间即可。

### 2. 推荐硬件连接

推荐使用 `SPI1`，只使用发送方向。

| STM32H743VGTx | DAC1220 模块 | 说明 |
| --- | --- | --- |
| `PA5 / SPI1_SCK` | `SCLK` | SPI 时钟 |
| `PA7 / SPI1_MOSI` | `SDIO` | SPI 数据输出 |
| `PA4 / GPIO_Output` | `CS` | 片选信号 |
| `GND` | `GND` | 共地 |
| `5V` | `+5V` | 模块供电 |

`MISO` 不接。DAC1220 的 `SDIO` 理论上是双向数据脚，但只写输出电压时不需要读回寄存器，所以可以使用 `SCK + MOSI + CS` 的最小连接。

### 3. CubeMX 中 SPI1 的配置

在 CubeMX 中进入：

```text
Pinout & Configuration -> Connectivity -> SPI1
```

设置如下：

| 参数 | 推荐设置 |
| --- | --- |
| Mode | `Transmit Only Master` |
| Direction | `Transmit Only Master` |
| Data Size | `8 Bits` |
| First Bit | `MSB First` |
| Clock Polarity, CPOL | `Low` |
| Clock Phase, CPHA | `2 Edge` |
| NSS | `Software` |
| Baud Rate Prescaler | 优先选 `512`，也可根据时钟选 `256` |

重点是：

```text
CPOL = Low
CPHA = 2 Edge
```

也就是常说的 SPI Mode 1。

DAC1220 模块手册给出的通信速率是 `250kHz`，因此 SPI 时钟不要配太高。

例如 SPI 外设时钟为 `100MHz` 时：

```text
100MHz / 256 = 390.625kHz，偏高
100MHz / 512 = 195.3125kHz，推荐
```

因此建议初次调试时使用：

```text
Baud Rate Prescaler = 512
```

调通后再根据实际波形和稳定性决定是否提高速度。

#### 3.1 Trace and Debug 设置

在 CubeMX / STM32CubeIDE 中，如果看到 `Trace and Debug` 这一栏，按下面方式设置：

| 项目 | Boot | Application | ExtMemLoader |
| --- | --- | --- | --- |
| `DEBUG` | 不勾选 | 勾选 | 不勾选 |

也就是：

```text
DEBUG:
  Boot        -> 不勾选
  Application -> 勾选
  ExtMemLoader -> 不勾选
```

这个设置的意思是：调试功能用于正常应用程序下载和调试，不作为 Boot 或外部存储加载器用途。

### 4. CubeMX 中 CS 引脚配置

把 `PA4` 配置为普通 GPIO 输出：

```text
PA4 -> GPIO_Output
```

参数建议：

| 参数 | 推荐设置 |
| --- | --- |
| GPIO output level | `High` |
| GPIO mode | `Output Push Pull` |
| GPIO Pull-up/Pull-down | `No pull` |
| Maximum output speed | `Low` 或 `Medium` |
| User Label | `DAC1220_CS` |

CS 空闲时保持高电平，发送数据前拉低，发送完成后拉高。

### 5. 引脚速度建议

DAC1220 是高精度模拟输出模块，数字信号边沿过快可能增加串扰。

建议：

```text
PA5 / SPI1_SCK  -> Low 或 Medium
PA7 / SPI1_MOSI -> Low 或 Medium
PA4 / CS        -> Low 或 Medium
```

如果 CubeMX 对 SPI 复用引脚默认生成 `Very High`，通常也能工作；但如果连线较长，建议在 `SCK`、`MOSI`、`CS` 串联 `50Ω ~ 100Ω` 电阻，模块原理图中也有类似的限流/阻尼设计。

### 6. 程序发送基础框架

CubeMX 生成代码后，通常会有：

```c
SPI_HandleTypeDef hspi1;
```

可以封装片选控制：

```c
static void DAC1220_CS_LOW(void)
{
    HAL_GPIO_WritePin(DAC1220_CS_GPIO_Port, DAC1220_CS_Pin, GPIO_PIN_RESET);
}

static void DAC1220_CS_HIGH(void)
{
    HAL_GPIO_WritePin(DAC1220_CS_GPIO_Port, DAC1220_CS_Pin, GPIO_PIN_SET);
}
```

SPI 写入函数：

```c
void DAC1220_WriteBytes(uint8_t *data, uint16_t len)
{
    DAC1220_CS_LOW();
    HAL_SPI_Transmit(&hspi1, data, len, HAL_MAX_DELAY);
    DAC1220_CS_HIGH();
}
```

### 7. 输出 0V 到 10V 的换算逻辑

模块选择 `±10V` 档时，目标输出范围是：

```text
-10V ~ +10V
```

如果只需要输出 `0V ~ 10V`，就在程序中限制目标电压：

```text
0V <= voltage <= 10V
```

20 位模式下可以理解为：

```c
code_20bit = (voltage + 10.0) / 20.0 * 0xFFFFF;
```

对应关系：

| 目标输出 | 码值位置 |
| --- | --- |
| `-10V` | 接近 `0x00000` |
| `0V` | 接近中码 |
| `+10V` | 接近 `0xFFFFF` |

如果使用厂家例程中的换算方式，`±10V` 档对应：

```c
double real_voltage = 0.25 * voltage + 2.5;
```

含义是：

| 模块目标输出 | DAC1220 内部等效电压 |
| --- | --- |
| `-10V` | `0V` |
| `0V` | `2.5V` |
| `+10V` | `5V` |

因此，成品模块通过后级调理电路，把 DAC1220 芯片本身的单极性输出转换成模块接口处的双极性输出。

### 8. 推荐调试步骤

1. 模块 H2 跳帽选择 `±10V` 档。
2. CubeMX 配置 `SPI1` 为 `Transmit Only Master`。
3. 配置 `PA5 = SPI1_SCK`，`PA7 = SPI1_MOSI`，`PA4 = GPIO_Output / DAC1220_CS`。
4. 供电前确认 `5V` 和 `GND` 没有接反。
5. 先输出 `0V`，用万用表确认模块输出接近 `0V`。
6. 再输出 `5V`，确认接近 `5V`。
7. 最后输出 `10V`，确认接近 `10V`。
8. 如果有固定偏差，可以后续加入两点校准。

### 9. 最终推荐配置汇总

```text
SPI1:
  PA5 -> SPI1_SCK
  PA7 -> SPI1_MOSI
  Mode -> Transmit Only Master
  Data Size -> 8 Bits
  CPOL -> Low
  CPHA -> 2 Edge
  First Bit -> MSB First
  NSS -> Software
  Prescaler -> 512

Trace and Debug:
  DEBUG -> Application 勾选
  DEBUG -> Boot 不勾选
  DEBUG -> ExtMemLoader 不勾选

GPIO:
  PA4 -> GPIO_Output
  Label -> DAC1220_CS
  Default level -> High
  Mode -> Output Push Pull
  Pull -> No pull
  Speed -> Low 或 Medium

DAC1220 模块:
  H2 跳帽 -> ±10V 档
  输出使用范围 -> 0V ~ 10V
```
